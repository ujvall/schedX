# Data Dictionary (Phase 2 dataset)

Generated by `python scripts/generate_dataset.py` into `artifacts/dataset/`.
All times are integer ticks. **Category** is the feature-availability class
defined in `schedx.features.CATALOG` (see `phase2_ml.md` §2):

* `id`, `target`, `generation`, `label_equivalent` — never model inputs.
* **A** — known at batch submission. **B** — online, from each process's
  first *k* CPU bursts. **C** — retrospective lifetime facts.

## `processes.csv` — one row per process

| Column | Type | Category | Definition |
|---|---|---|---|
| `workload_id` | str | id | Owning workload (`w<master_seed>-<index>`). |
| `pid` | str | id | `P0`, `P1`, … in arrival order. |
| `arrival` | int | A | Submission tick (first process arrives at 0). |
| `priority` | int | A | 0–4, lower = higher. Drawn independently of behaviour. |
| `cpu_bursts` | str | C | Full CPU-burst trace, `;`-separated. |
| `io_bursts` | str | C | Full I/O-wait trace between CPU bursts, `;`-separated; empty for a single-burst process. |
| `n_cpu_bursts` | int | C | Number of CPU bursts. |
| `total_cpu` | int | C | Sum of `cpu_bursts`. |
| `total_io` | int | C | Sum of `io_bursts`. |
| `io_fraction` | float | label_equivalent | `total_io / (total_cpu + total_io)`. |
| `process_kind` | str | label_equivalent | `io_bound` if `io_fraction > 0.5`, else `cpu_bound`. |
| `intended_kind` | str | generation | Which parameter range the generator drew from. Differs from `process_kind` for ~3% of processes. |

## `workloads.csv` — one row per workload

| Column | Type | Category | Definition |
|---|---|---|---|
| `workload_id` | str | id | |
| `master_seed` | int | generation | Dataset seed. `default_rng([master_seed, workload_index])` regenerates the workload. |
| `workload_index` | int | generation | Index within the dataset. |
| `regime` | str | generation | `cpu` / `io` / `mixed`: the generator's intended mix. **Not the label.** |
| `p_io` | float | generation | Probability each process is drawn I/O-heavy. |
| `mean_interarrival` | float | generation | Mean of the exponential arrival gaps (intensity). |
| `burst_cv` | float | generation | Coefficient of variation of burst lengths. |
| `n_processes` | int | A | Process count. |
| `share_io` | float | label_equivalent | Fraction of processes with `process_kind == io_bound`. |
| `workload_class` | str | target | `cpu_bound` if `share_io <= 0.25`; `io_bound` if `>= 0.75`; else `mixed`. |

## `features.csv` — one row per (workload, horizon *k*)

Each workload appears once per horizon in `dataset.horizons` (default 1, 2, 3).
These rows are correlated, so splits are always by `workload_id`.

| Column | Category | Definition |
|---|---|---|
| `workload_id` | id | |
| `n_processes` | A | Number of submitted processes. |
| `arrival_span` | A | Last arrival − first arrival. |
| `arrival_gap_mean` | A | Mean gap between consecutive arrivals. |
| `arrival_gap_std` | A | Population std of arrival gaps. |
| `arrival_rate` | A | `n_processes / (arrival_span + 1)`. |
| `priority_mean`, `priority_std` | A | Mean / population std of priorities. |
| `horizon_k` | B | Number of CPU bursts per process observed so far. |
| `obs_cpu_mean`, `obs_cpu_std`, `obs_cpu_min`, `obs_cpu_max`, `obs_cpu_median` | B | Statistics over all observed CPU bursts (first `min(k, n)` per process). |
| `obs_proc_cpu_mean_std` | B | Std across processes of each process's mean observed CPU burst (high for mixed workloads). |
| `obs_io_mean`, `obs_io_std` | B | Statistics over observed I/O waits (first `k − 1` per process). **Missing at k = 1.** |
| `obs_io_cpu_ratio` | B | Σ observed I/O / Σ observed CPU. **Missing when no I/O observed.** |
| `obs_frac_io_dominant` | B | Among processes with observed I/O, fraction whose observed I/O exceeds observed CPU. **Missing when no I/O observed.** |
| `obs_io_per_proc` | B | Observed I/O waits / `n_processes` (0 at k = 1). |
| `obs_frac_terminated` | B | Fraction of processes that finished within `k` CPU bursts. |
| `total_cpu_mean`, `total_io_mean` | C | Mean lifetime CPU / I/O per process. |
| `lifetime_io_fraction` | C | Σ I/O / (Σ I/O + Σ CPU) over the workload. |
| `bursts_per_proc_mean` | C | Mean CPU-burst count. |
| `cpu_demand_per_tick` | C | Σ lifetime CPU / (`arrival_span` + 1). |
| `workload_class` | target | Copied from `workloads.csv`. |

Missing values are left as empty cells (NaN), never zero-filled. Models
impute them inside the training pipeline (median fitted on training data,
plus missing-indicator columns).

## `dataset_meta.json`

`dataset_version` (hash of the dataset + generator config), the full
config, row counts, and the class distribution.
